# 🐰 兔吃了么 · 每日饮食底稿注入插件

> 一句话：**给你的兔子每天悄悄排一份饭，被问到"今天吃了啥"时能像真人一样答上来，不装腔作势也不复读。**

---

## 一、这插件到底干啥？

以前你问 AI：「今天吃了啥？」
它可能说：「作为一个人工智能，我并不需要进食……」
或者装模作样：「今天吃了红烧狮子头配米饭。」（明天问还是这一句）

这插件做的事：
1. **每天凌晨（或第一次被问到时）自动排一份菜单** —— 早/午/晚/加餐都有
2. **只在 AI 生成回复前，把菜单悄悄塞进 system_prompt**（用户看不见，AI 心里有数）
3. AI 被问到吃喝时，自然带出来，**不会主动去炫菜单**
4. 一份菜单存一整天，同一天问多次答的是同一顿；第二天自动换新

菜单从哪来：
- **优先** 让 LLM 生成（可以指定用哪个 provider）
- LLM 挂了 → 回退到本地食物库，按权重随机
- 权重规则：喜欢的菜出现概率高、时段对得上的加分、连着几天出过的会避开

## 二、装完之后怎么开始用？

### 1. 装完先打开 AstrBot 管理面板，找到 "兔吃了么"，看下配置

关键几个：

| 配置项 | 干啥的 | 默认 |
|---|---|---|
| `enable_inject` | 总开关，关了就完全不注入 | ✅ 开 |
| `use_llm_gen` | 是否允许 LLM 生成菜单（总开关，关了直接走本地池） | ✅ 开 |
| `llm_ratio` | **LLM 生成的概率（0.0 ~ 1.0）**。1.0=每天都优先 LLM；0.0=全走本地池；0.5=一半概率走 LLM、一半走本地库 | 1.0 |
| `llm_provider_id` | 用哪个 provider 生成菜单，**AstrBot 里配过的会自动出现在下拉框**，留空=用当前会话默认的 | 空 |
| `trigger_keywords` | 命中关键词才注入（比如 `["吃","饭","饿"]`），**留空 = 全场景都注入** | 空 |
| `lazy_ratio` | 摆烂概率，0-1，越大越常"一顿只吃一样" | 0.4 |
| `weird_ratio` | 怪味出现概率，0-1，控制"糖醋拿铁"这种奇葩菜的频率 | 0.1 |
| `include_snack` | 要不要有加餐/甜点 | ✅ 开 |
| `dedup_days` | 最近几天吃过的菜避开不重复 | 7 |
| `snippet_template` | **注入到 system_prompt 的文案模板**，可用占位符 `{menu}` / `{breakfast}` / `{lunch}` / `{dinner}` / `{snack}`。清空即回退默认 | 见下 |
| `gen_prompt_template` | **让 LLM 生成菜单时用的 prompt 模板**，可用占位符 `{today}` / `{season_hint}` / `{recent}`。清空即回退默认 | 见下 |
| `gen_system_prompt` | LLM 生成菜单时的 system_prompt，改口吻/人设用 | "你是一个菜单助手…" |

### 2. 网页配置

如果你想手动管理食物库、看今天吃啥、随时重摇：

| 配置项 | 说明 |
|---|---|
| `web_enable` | 启动小网页 |
| `web_host` | 监听地址：**本机用 `127.0.0.1`，云服务器用 `0.0.0.0`** |
| `web_port` | 端口，默认 17334 |
| `web_token` | 访问密码，**用 0.0.0.0 时必填**！不填等于裸奔 |

启动后浏览器打开 `http://你的IP:17334`，输密码就进去了。

### 3. 会话开关

不想在某个群/某个人那里生效？直接在 AstrBot 的会话管理里 **禁用本插件** 即可，指令和 hook 都会被拦住。

## 三、自定义 Prompt / 注入文案（重要）

三个模板都在配置页里，直接改就行。**清空任何一个都会自动回退到内置默认，改坏了不用怕。**

### 1. `snippet_template` —— 每次注入给 AI 看的那句话

默认长这样：

```
[今日吃食] {menu}（被问到时自然带出，别主动罗列、别复读；请结合当前时间判断该聊哪一顿：还没吃就说打算吃，吃过了就说吃过了）
```

可用占位符：

| 占位符 | 含义 |
|---|---|
| `{menu}` | 拼好的整句：`早 X ｜ 午 Y ｜ 晚 Z ｜ 想吃 W` |
| `{breakfast}` / `{lunch}` / `{dinner}` / `{snack}` | 各餐单独字段，空的自动填「（无）」 |

想按顿分开强调、或者换种口吻讲都随意。

### 2. `gen_prompt_template` —— 让 LLM 排菜单的正文

默认长这样：

```
给他排一份今天的饮食（早/午/晚/加餐）。要求：
1. 早/午/晚各 1 项，加餐 1 项（不需要就给空字符串）。
2. 追求真实生活感，街边小吃 / 家常菜 / 精致小食都可以，避免连锁快餐凑数。
3. 他是重度肉食+嗜甜口味，喜辣，也偶尔会来点清奇怪味。
4. 今天是 {today}，节气/时令：{season_hint}，可以适当贴合。
5. 避开最近吃过的：{recent}
6. 只返回一个严格 JSON 对象，键为 breakfast/lunch/dinner/snack，值为菜名字符串（可以是一顿的多样搭配，用 + 连接），不要任何多余文字、不要 markdown 代码块围栏。
示例：{"breakfast":"煎饼果子+豆浆","lunch":"红烧肉+白粥+冬瓜排骨汤","dinner":"麻辣香锅","snack":"焦糖蛋挞"}
```

可用占位符：

| 占位符 | 含义 |
|---|---|
| `{today}` | 今天日期 |
| `{season_hint}` | 当前节气/时令 |
| `{recent}` | 最近几天吃过、要避开的菜 |

⚠️ **必须保留的硬性要求（缺一个都会让菜单解析失败）：**

1. 让 LLM **只返回一个严格 JSON 对象**，不要多余文字、不要 markdown 代码块围栏
2. JSON 的键必须是 `breakfast` / `lunch` / `dinner` / `snack` 这四个（少一个就少一顿）
3. 值是菜名字符串，可用「+」连接多样搭配

**可以随便改的：** 口味描述、风格倾向、要不要贴合节气、给菜品限定地域（想吃"川湘菜为主"或"苏杭清淡菜"都行）、要不要考虑健康均衡等。

### 3. `gen_system_prompt` —— LLM 生成菜单时的系统提示词

默认：

```
你是一个菜单助手。只返回严格 JSON，不要解释、不要 markdown 代码块。
```

改这里主要是定角色/口吻。⚠️ 别删「只返回严格 JSON、不要 markdown 代码块」这句，不然模型可能加代码块围栏，解析崩。

## 四、小网页有啥？

三个 Tab：

### 【今日】
- 显示今天的早/午/晚/加餐
- 每一顿旁边有个 🎲 骰子按钮 → **单独重摇这一顿**
- 底部有 "全部重摇" → 一键推翻重来
- 底下 Snippet 预览就是 AI 会看到的原文

### 【近几天】
- 看过去 10 天吃过啥
- 别删 history.json，删了就没这个功能了

### 【食物库】
- 一个大表格，能改所有菜的：**名字 / 喜好度 / 品类 / 时段 / 怪味标签**
- 可以搜索、按品类/喜好过滤
- 可以直接 ➕ 新增菜，❌ 删菜
- **改完记得点右上角"💾 保存所有改动"**，不然刷新就没了

## 五、食物库怎么打标签？

一条菜长这样：

```json
{
  "name": "麻辣香锅",
  "love": 1,
  "cat": "配菜",
  "time": ["晚"],
  "weird": false
}
```

| 字段 | 说明 |
|---|---|
| `name` | 菜名，越具体越好（"番茄鸡蛋辣椒面" > "面条"） |
| `love` | 喜好度：**0=一般 / 1=喜欢 / 2=特别喜欢**（2 号权重是 0 号的 10 倍） |
| `cat` | 品类，只能填这五个：主食、配菜、汤、甜点、饮品 |
| `time` | 时段偏好，可选 `["早","午","晚","加"]` 的组合。**留空=无偏好**；填了：命中权重 ×1.8，不命中 ×0.35 |
| `weird` | 怪味菜（糖醋拿铁、魔鬼辣泡面这种）设 `true`，会按 `weird_ratio` 的概率参与 |

## 六、生成逻辑（想搞懂再看）

每天生成分两种模式，按 `lazy_ratio` 摇骰子：

**A. 正经搭配（默认 60%）**
- 主食 × 1
- 配菜 × 1~2（55% 一样、45% 两样）
- 30% 概率带一份汤（午/晚才带）
- 早餐 40% 概率带一杯饮品

**B. 摆烂模式（默认 40%）**
- 一顿就一样菜（早餐限主食，午晚可选主食或配菜）
- 模拟"懒得做/外卖一份完事"的真实感

加餐单独判断：55% 概率有，从甜点/饮品/加餐主食里挑一样。

## 七、数据存哪？

`AstrBot根目录/data/plugins_data/xavier_daily_meal/`

- `foods.json` —— 你的食物库（第一次启动自动生成，后面就归你管了）
- `history.json` —— 每天的菜单历史

**这两个文件删了就等于重置。** foods.json 删了会重新用默认库生成。

## 八、云服务器部署的注意事项

如果你把 AstrBot 装在服务器上，想用小网页：

1. `web_host` 改成 `0.0.0.0`
2. **一定填 `web_token`**！随便一段密码就行，比如 `abc123XYZ!`
3. 服务器安全组/防火墙放行 `web_port`（默认 17334）
4. 浏览器访问 `http://服务器IP:17334`，输密码
5. Cookie 30 天有效期，不用天天输

**不填 token 时插件会在日志里 WARN**，那样任何人扫到你的 IP 都能改你的食物库。

## 九、常见问题

**Q：AI 还是不带饭说话？**
- 会话里插件是不是被禁用了？（AstrBot 管理面板 → 会话管理）
- `enable_inject` 是不是关了？
- 设了 `trigger_keywords` 但用户消息里没命中？留空试试
- 看下 history.json，今天有没有生成菜单

**Q：菜单一直是同一份，不换？**
- 一天内不换是正常的（就像你不会一天换三次今天吃啥）
- 想手动换 → 打开小网页点 "全部重摇"

**Q：想让 AI 用小号模型专门跑菜单，不占大号 quota？**
- 在 AstrBot 里配一个便宜的 provider（比如 gpt-4o-mini）
- 打开插件配置，`llm_provider_id` **下拉框**里直接选它就行（不用手打 id）

**Q：LLM 生成出来的菜看不懂/太离谱？**
- 关掉 `use_llm_gen`，全走本地池，保证输出都在食物库里
- 或者去食物库删掉那些"看不懂"的候选

**Q：一直吃辣不健康怎么办？**
- 打开小网页 → 食物库 → 把辣菜的 `love` 从 1 改成 0，权重就低了
- 或者把喜欢的清淡菜升到 love=2
